# Node.js Express API Hub

A simple and scalable backend API hub built with **Node.js** and **Express.js**. This project demonstrates a clean architecture using controllers, middleware, and routes, following RESTful API design principles and backend development best practices.

## Features

- Express.js server setup
- RESTful API architecture
- Modular folder structure
- Route handling with Express Router
- Controller-based business logic
- Custom middleware support
- Authentication middleware
- Error handling middleware
- Environment variable configuration
- Scalable and maintainable codebase

## Tech Stack

- Node.js
- Express.js
- JavaScript (ES6+)
- dotenv
